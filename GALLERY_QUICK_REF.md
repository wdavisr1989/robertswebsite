# Gallery CMS Quick Reference

## 🎯 Quick Access

**URL**: `yourwebsite.com/admin` → Click "Wall of Fades"

## ➕ Add New Image

1. Click **"New Gallery Image"**
2. Upload image
3. Set title and caption
4. Choose display order (1, 2, 3...)
5. **Publish**

## ✏️ Edit Image

1. Click image from list
2. Update fields
3. **Publish** changes

## 🔄 Reorder Images

- Edit image → Change **Display Order** number
- Lower numbers = earlier position (1 shows first)
- Tip: Use 10, 20, 30... for easy insertion

## 👁️ Hide Image

- Toggle **Published** OFF or **Featured on Homepage** OFF

## 🗑️ Delete Image

- Edit → **Delete** button → Confirm

## 📊 Image Specs

- **Size**: 800x800px to 1200x1200px
- **Format**: JPG or PNG
- **Max File Size**: Under 500KB

## 🏷️ Categories

- **Haircuts** - Standard cuts, fades
- **Beards** - Beard work
- **Styles** - Creative designs
- **Other** - Everything else

## ✅ Checklist Before Publishing

- [ ] Image uploaded
- [ ] Title added
- [ ] Display order set
- [ ] Published = ON
- [ ] Featured = ON
